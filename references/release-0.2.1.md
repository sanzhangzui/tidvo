# Tidvo 0.2.1 Beta

**对话式磁盘清理，为 AI Agent 和开发环境做了专门优化。**

安装后直接说：

> 帮我清理一下电脑。

Tidvo 会先检查占用、推荐清理清单、解释影响，确认后再执行。
只想了解占用时说：“看看哪里占空间。”
工作数据保护、保留开发依赖和结果总结都由技能默认处理。

本次更新：

- 将磁盘清理作为主入口，Agent 定制保护作为默认能力。
- 普通短请求默认进入检查与清理建议流程，用户无需指定模式或候选 ID。
- 扫描结果新增磁盘总容量、已用和可用空间，并区分已识别候选与全盘占用。
- 中英文首页、技能展示和安装完成提示统一使用简单表达。
- 一句话安装说明自动选择已发布的独立技能包，支持当前 Beta 版本。

一句话安装：

> 帮我安装 Tidvo：https://raw.githubusercontent.com/sanzhangzui/tidvo/main/INSTALL.md

需要能操作本机文件和终端的 AI 工具、macOS 14+ 与 Python 3.11+。
Windows 支持规划中。当前检查重点是已知缓存和开发产物，覆盖范围会在报告中
说明。移入废纸篓通常不会立即释放空间，恢复依赖原载荷仍在。

旧版安装可请求 AI 更新 Tidvo，保留已有配置和恢复记录；旧计划需重新扫描生成。
GPL-3.0-only；包含固定版本的 Mole 源码与修改说明。
