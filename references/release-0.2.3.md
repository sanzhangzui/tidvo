# Tidvo 0.2.3 Beta

清理推荐前同时检查应用安装状态与进程状态，区分“仍安装”“搜索范围内未发现”
和“检查不完整”。通过安装目录、Info.plist Bundle ID 与 Spotlight 识别重命名、
子目录及非标准位置中的副本。

已确认卸载且已授权清理的应用，可直接按专属路径批量处理卸载残留，包括内部
设置、历史、会话和私有数据库，无需逐文件再次确认。本版提供 Dia、Chrome、
Obsidian 和 VS Code 四个精确路径适配；不是所有应用的通用卸载器。共享目录、
项目、外部知识库和独立 Agent 保护资源仍保留。仅搜索未找到不等于已确认卸载。

执行前及占用检查后再次核对安装与引用状态；重新安装、仍在运行、检查不完整、
路径变化等情况均保留文件。仍只移入废纸篓并保存恢复记录，不永久删除、不提权、
不自动清空废纸篓。配置和历史记录保持兼容；旧清理计划需重新生成。

详细范围见 references/uninstalled-apps.md。Windows 支持仍在规划中。
